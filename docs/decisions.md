# Project decisions

- **Corpus:** Arthur Conan Doyle's *The Adventures of Sherlock Holmes*, Project Gutenberg #1661. The planned source format is Gutenberg's UTF-8 TXT. The original was downloaded and validated in Phase 2; its bytes are kept unchanged in ignored local data.
- **Python:** Use Python 3.11 in a dedicated `sherlock-rag` conda environment.
- **Packaging:** Use a `src/` layout with setuptools. Install the project in editable mode for development.
- **Dependencies:** Add them only when a phase needs them. Phase 1 has no runtime dependencies; its development extra contains pytest and Ruff.
- **Retrieval:** Phase 4 uses an in-memory, standard-library BM25 lexical baseline over verified `chunk.text` only, with k1=1.2, b=0.75, positive Robertson IDF, and Unicode casefold tokenization. Phase 5a adds a pinned local Qwen3-Embedding-0.6B exact-cosine baseline over the same text and frozen gold set. Queries receive one fixed instruction; documents do not. Phase 5b compared equal-weight RRF against both individual methods and selected semantic A for Phase 6 by a predeclared dev-only rule.
- **Models and services:** Phase 5a pins Qwen3-Embedding-0.6B for retrieval. Phase 6a uses local Qwen/Qwen3-4B-Instruct-2507 at commit `cdbee75f17c01a7cc42f958dc650907174af0554` with bfloat16 MPS; no paid API is used.
- **Chunking:** Use deterministic sliding windows within each story. Sizes of 250/50 and 500/100 mean `\S+` whitespace-delimited words and overlap, not model tokens. Preserve exact book substrings and source-line provenance.

- **Phase 5b selection rule (fixed before hybrid measurement):** Compare all six method/configuration pairs on answerable dev questions only. Select the highest Hit@5; break ties by highest MRR@5, then lowest mean returned top-five whitespace words. If still tied, use this fixed order: BM25 A, BM25 B, semantic A, semantic B, hybrid A, hybrid B. Report test separately; do not tune the 20/60 RRF parameters or the gold set from test results.
- **Phase 5b result:** Semantic A and hybrid B tie at dev Hit@5 7/12 and MRR@5 .500. Semantic A wins the predeclared context tie-break (1229.1 versus 2422.4 returned words) and is selected for Phase 6 in `config/retrieval.json`. Hybrid remains available for comparison.
- **Phase 6a grounding:** Keep the selected semantic A retriever and top five. Show whole ranked passages with labels C1–C5, normalize only whitespace while retaining raw Unicode offset spans, and measure the entire chat template against a 6144-token input budget. Drop whole lowest-ranked passages as needed. Generate at most 768 new tokens greedily. Validate JSON, source labels, and exact displayed quotes; map the first occurrence of a repeated quote to the original book. Permit one mechanical repair attempt using the same passages. Citation resolution is not semantic entailment; full answer and abstention evaluation is Phase 6b.
- **Phase 6b evaluation freeze (before generation):** Retain the original 30-question file SHA-256 `fb2dfa8a302055b9993f06933d4fa15190041ca411b582ad5263336f3192de0b`. Add 12 source-reviewed challenge questions (six unmentioned in-book details, four false premises, two outside-corpus requests) in `eval/answer_challenges.jsonl`, SHA-256 `cdf59802eeeddde1b3d0430651d999abcc51f5f1186a36b44a8a8bd0fdafe006`. Every in-book reference was checked against its story. This internally authored set follows earlier findings and is not an independent final benchmark. Freeze the system settings and raw results before reviewing content; do not tune generation during this baseline.
- **Phase 6b measured baseline:** The 42 local outputs were frozen at SHA-256 `18019b31adec06a9ea061e5794e4ffa87317cb6c7160c70a4f7bacc4621d7721` before the separate implementation-agent review. The reviewed 24 original answerable cases yielded 10 supported correct answers, five displayed answers with unsupported claims, and seven contexts without adequate answer evidence. These findings warrant a separately reviewed quality-improvement task; neither questions nor pipeline settings were changed to improve this baseline.
- **Phase 6b review fix:** Preserve `baseline_v1` as a legacy frozen run. Its original fingerprint hashed only `rag.py` among project code and therefore did not guard against changed retrieval modules. Fingerprint schema v2 hashes deterministically ordered paths and contents of all package Python source for new runs; a mismatch rejects resume before model loading or writing. Review of the old frozen result remains available. Treat a saved `runner_error` with missing attempts, tokens, or time as a technical error with explicitly incomplete measurement coverage, never as a refusal or a zero-cost generation.
- **Phase 6c1 pre-run freeze:** Test only `local-answer-v2-candidate` as an explicit variant using the existing model/revision, MPS bfloat16, greedy decoding, budgets, repair limit, and semantic A passages. The candidate and comparison protocol were recorded with SHA-256 hashes before generation; no iteration followed the 42-case result. The runtime fingerprint includes the selected prompt and generation config. Baseline v1 stays the default and its frozen outputs remain historical.
- **Phase 6c1 decision:** The candidate improved reviewed supported-correct original answers from 10/24 to 14/24, but the number of displayed answers with unsupported claims remained five and a false Bible-copying premise was accepted. Keep v2 experimental and v1 as default. This is an internal regression comparison using previously seen test/challenge cases, with implementation-agent rather than independent human semantic review. See [answer reliability report](answer-reliability.md).
